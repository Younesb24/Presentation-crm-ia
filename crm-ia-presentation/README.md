# CRM et intelligence artificielle

Présentation du module **Outils CRM** (ENSAO Oujda) : usages, bénéfices et limites de l’IA dans un CRM, avec une étude de cas sur **Agentforce dans Salesforce**.

Version en ligne : `https://<votre-nom-utilisateur>.github.io/<nom-du-depot>/`

## Navigation

| Touche | Action |
|---|---|
| `→` `↓` `Espace` `Entrée` ou clic | Animation suivante / diapositive suivante |
| `←` `↑` ou clic sur le bord gauche | Diapositive précédente |
| `F` | Plein écran |
| `G` | Aller à une diapositive |
| `N` | Afficher / masquer les notes de présentation |
| `Début` / `Fin` | Première / dernière diapositive |

Sur téléphone ou tablette : balayer vers la gauche ou la droite.

On peut aussi ouvrir directement une diapositive avec son numéro dans l’adresse, par exemple `#8` pour le cas pratique.
